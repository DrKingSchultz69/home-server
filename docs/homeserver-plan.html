Design rules

Confirmed rules

Nothing public

No router ports are opened. Remote access only through Tailscale.

Approved devices only

Device approval is on. Only approve devices you know are safe. Key expiry stays on.

You vs family

Your laptop and phone reach everything. Family devices reach the dashboard, their own files folder and streaming: ports 443, 8444 and 8445 only.

Private services stay private

Services listen on 127.0.0.1 and reach the tailnet only through Tailscale Serve. Port 4141 is never published.

Streaming is isolated

Separate streamer user in a hardened systemd service: sees only the media folders, read-only, 256 MB memory box. No VM.

Lost device plan

Remove it in the Tailscale admin console, sign out all sessions, remote-wipe, rotate keys and tokens.

Open items

Known issues

No server backup yet

Everything lives on one SSD. Pick a backup destination (USB drive, the laptop, or cloud) before family photos are only on the server.

Tailscale SSH and SELinux

Accepted trade-off: Tailscale SSH sessions run in a service security context. sudo works. Fallback if it ever breaks: the desktop's own keyboard.

Weekly restart

Security updates install daily but never reboot on their own. Restart the server about once a week so kernel updates take effect.

Ethernet stuck at 100 Mbps

The desktop links at 100 Mbps instead of 1 Gbps. Ruled out: card, settings, cable category. Next test: reseat the plug, try the router port the laptop uses.

GT 710 still detected

The server's hardware list still shows the GT 710. If apps crash or the screen glitches, take the card out completely.

8 GB of RAM

The desktop already uses about 3.4 GB. Netheron agents, streaming and a game server will compete; +8 GB DDR4 is the cheapest upgrade.
